# Shared-event assertions from related signals

Related signals contain facts about other events. Their presence does not prove
that locations experienced one physical event, shared system or causal mechanism.
The existing deterministic cross-signal check covered many causal phrases but
missed compact assertions such as “one dust event.”

The same check now recognizes one/single/same followed by a bounded weather-event
vocabulary. It normalizes whitespace and common Unicode hyphens for that rule,
with word boundaries and at most two weather qualifiers. Existing substring rules
keep their behavior and diagnostics. No related context leaves this gate inactive;
every other applicable check still runs. Place/date enumeration such as “one
country” or “the same day” is eligible for those checks.

As with the prior conservative gate, quotes and negations do not override a
recognized phrase. The vocabulary is intentionally bounded and cannot establish
general semantic entailment. False positives remain possible; this is not a
classifier of physical weather events or proof that two events were separate.

Synthetic tests exercise recognized assertions, spelling/spacing boundaries,
allowed enumeration and the synchronous and experimental check paths. A rejected
candidate purchases no downstream safety, factual or critic call. Passing the
local rule never grants a factual or posting approval.

The triggering runtime review concerned pending drafts. Their saved summaries
omit part of the original writer input, so a private predicate replay using an
explicitly assumed related context is not a full original-input reproduction.
No exact private draft text is included in public fixtures or this handoff.

The policy identity changes so earlier reviews cannot silently remain current.
Retained drafts, receipts and approval fields are untouched. Runtime prompts,
models, one routine sample and publishing settings remain unchanged. Shorter,
better writing and measured cost savings need separate evidence.
