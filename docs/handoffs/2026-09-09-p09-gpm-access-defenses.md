# P09: local GPM access-failure containment

The access diagnosis is preserved in `2026-09-09-p09-gpm-access-evidence.md`. Retained expiry metadata, the repository secret's update date and existing HTTP 401 results strongly support an expired Earthdata token as the first recovery blocker. This patch reduces futile requests and corrects failure classification. It does not renew a credential, prove NASA access or resolve the historical rainfall discrepancy.

## Changes

- Before any NASA request, use the existing JWT-expiry parser on the configured token. A known expiry at or before the current UTC instant raises an explicit `SourceFetchError`. Only the derived timestamp appears in that message. Unknown/opaque/malformed expiry and future expiry still require the real endpoint to establish access; an unverified claim never grants authentication. Strict collection surfaces the failure; the existing non-strict API keeps returning no readings. This known-expiry refusal cannot activate the model witness, preserving the existing per-exception witness policy.
- Remove unconditional S3 credential preminting from the source runner. Credentials are requested only if an explicitly selected S3 path needs them.
- Remove direct S3 from the automatic datapool-HTTPS fallback. NASA documents [same-region direct S3 access](https://data.gesdisc.earthdata.nasa.gov/s3credentialsREADME); an HTTPS outage does not establish that execution capability. Explicit `s3` selection remains available for a separately qualified deployment and retains its existing HTTPS fallback. No workflow variable, hosting region or account is changed.
- Advance S3 date lookback only for missing-object evidence. Ambiguous 403/AccessDenied, expired/invalid credentials and a missing bucket stop that date walk. A permission failure cannot establish that yesterday's object will exist. Other existing fallback behavior is unchanged.

The full valid downloaded-grid watchlist, 75-city remote-path caps and bounded request retries remain. No new model stage or source call is added. Expired-token tests trap every NASA and independent-witness boundary; they demonstrate zero calls at and after expiry. Separate tests prove unknown/future expiry still reaches the access boundary and denied S3 requests do not spend the date-lookback budget. The real runner regression confirms that a normal fetch makes no S3 premint attempt.

## Validation and remaining work

The GPM/watchlist/access/credential/witness suites pass **112 offline tests**. Direct Ruff and mypy pass for both changed production files. Independent review found and fixed a conflicting-status edge case: an HTTP 401/403 or auth code takes precedence over a simultaneous missing-key code, so ambiguity cannot buy extra date probes. Public fixtures use fabricated token payloads and mocked provider boundaries; no credential value, NASA request, model request, account change or production state write was used.

Token renewal still requires a valid authorized authentication context. NASA now documents a [Bearer token renewal endpoint](https://urs.earthdata.nasa.gov/documentation/for_users/user_token); this patch does not establish whether the currently expired token could be renewed there, invalidate a token used elsewhere, or update repository secrets. Do not claim an account login is the only possible future renewal mechanism. A working credential and a bounded canonical-product read remain prerequisites for access recovery.

Sanitized status/content-type/redirect diagnostics for the existing S3 mint helper, compatibility of its Bearer flow with the endpoint, and a verified credential lifecycle remain follow-up work. The inherited grid-to-OPeNDAP chain can also lose an earlier failure classification: a grid authentication failure followed by a separate OPeNDAP outage exposes only that final outage to witness eligibility. This patch establishes known-expiry containment, not a complete multi-leg failure history. No new authenticated probe is requested by this patch. Satellite product/grid validation and Barrow's granule/window/footprint reconciliation remain separate scientific acceptance requirements. Automatic publishing stays paused; no public correction is authorized.
