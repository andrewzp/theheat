## Minimum private evidence and acceptance for one pilot per region

Apply this checklist to one explicitly named station in each region. Reuse retained source bytes if available; any subsequent acquisition needs its own bounded task. A failed candidate receives a specific gap disposition before another source is considered.

1. **Identity and access packet.** Retain station/product identifiers, metadata version and original bytes, coordinates/elevation, variable/units, source URL, retrieval time, payload hash, reporting-day convention, QC definitions, documented access/redistribution terms and known request/cost limits. Record unknowns explicitly. A city name or nearest grid point is not a station join.
2. **Actual observation packet.** Retain one timely original TMAX or TMIN source-day reading, accepted source QC and the exact parsed value. Where discovery uses `recentdiff`, retain that input and its reconciliation with the station archive too. Preserve date-only semantics when the observation interval/timezone is unknown; retrieval time is not observation time. Missing values and rejected QC cannot become zero or an accepted daily extreme.
3. **Separate value and comparison gates.** A qualified observed value can demonstrate ingestion even if it is not record-worthy. A record pilot additionally needs the same station/source/variable's original archive, strictly prior comparator value/date, candidate exclusion from its own baseline, requested versus verified cutoff, accepted sample counts and per-tier years, and missing/QC/conflict/omitted-interval diagnostics. Reuse `record_comparison_qualified` and the existing detector/audit gates. An incomplete baseline earns an explicit narrower observation/gap disposition, never invented record wording. Current record-first routing may still yield no editorial signal; report that separately from ingestion success.
4. **Controlled route and budget.** In a later implementation, add an explicit pilot allowlist through the non-US partition, preserving station identity and typed forecast/observed alternatives. Do not switch the entire bot to `ghcn`, relabel the forecast lane or bulk-warm baselines. Retain the hard 20 archive attempts per run, shared tracked/new lanes, normal individual publication caps and deduplication. Current fair-selection bounds require fixed pools and consecutive four-hour execution buckets; retries, skipped buckets, churn, source delays and overflow must remain visible. Inventory size does not prove an acceptable revisit interval.
5. **Private end-to-end replay.** With networking and model providers blocked, replay retained raw bytes through extraction, qualification, `StoryBundle`, P05 eligibility and deterministic claim checks. Inspect the exact evidence and an explicitly private local graphic where supported. Demonstrate correct refusal for a QC-rejected candidate, stale/missing comparator, forecast mislabeled as observation, changed source revision and mixed trajectory snapshots. Any later copy test and joint text/media approval is a separate step. Existing receipts and published/uncertain posts must remain unchanged.
6. **Measured pilot disposition.** For each region report accepted station/day/variable packets, comparator-qualified packets, route/eligibility outcomes and private outputs separately. Record source valid day, arrival/retrieval lag, retry/failure/withholding reasons and actual requests/cost; one successful payload does not establish a latency service level. Finish with either one evidenced end-to-end observed pilot or a named blocker such as no timely GHCN data, insufficient qualified history, unavailable access/rights, or no supported route.
7. **Coverage claim gate.** Compare the pilot and incumbent forecast lane on an independently selected, dated reference-event set with station/grid and forecast/observed support kept explicit. Track discovered, evidenced, eligible and selected outcomes plus miss reasons. A forecast's later verification is an evidence update, not a second event. No incremental recall or regional completeness claim is warranted until that denominator and the actual results exist; three pilots would demonstrate three pilots only.

**Recommended next bounded slice:** first qualify whether the three inventory candidates have timely, usable source days; Spain is not automatically ready and the retained Indian/South African candidates have conspicuous last-year gaps. If GHCN cannot support one region, record the evidence-backed failure and qualify the named national-service candidate's access contract before writing an adapter. The reuse opportunity is real; the present local evidence cannot decide source latency or select a successful station.
