# Screen unsupported cyclone landfall candidates before writing

The previous detector accepted a bare `landfall near/in/along` substring. Forecast,
negated and historical statements could therefore enter the completed-landfall
story queue. The existing scientific gate stopped unqualified completed copy later;
this change screens the candidate earlier, before writing.

The detector now requires a direct affirmative completion clause naming the current
storm. It preserves explicit made/has made/just made forms and classification/center
prefixes. Forecasts, negation, conditional or uncertain language, historical markers,
other-storm names and conflicting same-storm clauses are withheld. Literal names,
common place abbreviations, initials and decimal punctuation have focused fixtures.

This is conservative lexical screening, not a confirmation adapter. Unsupported
wording can withhold valid reports; no broad natural-language recall is established.
Current advisory category, wind and issue time do not establish observed landfall
intensity or time. An accepted candidate still lacks a source warrant and cannot
pass the unchanged scientific gate on that basis. No model can fabricate a pass.

The existing candidate schema/identities and category threshold are retained.
Forecast land threats, rapid intensification and tier changes use their existing
paths. The NHC product URL/time repair is preserved. Models, prompts, sample count,
production storage and publishing controls remain unchanged.

## Validation and release boundary

217 focused offline tests cover the detector, restored NHC product text, source-to-
queue wiring, the independent no-paid-check gate, other cyclone paths and editorial
policy. A 13-case synthetic comparison removes ten known false candidates while
preserving its three intended positives. These are regression fixtures, not a
reference-event recall study or evidence of a bad historical public tweet.

One location-punctuation regression initially failed and was fixed; the original
factual gate assertions remain intact even when no candidate is emitted. Full
release tests and exact-head CI are recorded separately at release. The shared
cyclone module is now policy-bound, requiring manual dashboard deployment for the
generated manifest. No paid provider trial or production publication is authorized
by this code release. Invoice savings, real source recovery and broader coverage
remain unmeasured.
