# TheHeat: six product outcomes govern the upgrade

Andrew clarified these priorities on September 9 while implementation was under way. They supersede any sequencing that postpones editorial quality, operating cost or graphics until an extensive infrastructure rewrite is complete. Continue the existing assessment and its evidence; do not restart the audit or count infrastructure activity as product success.

## Outcomes and proof

| Problem | Required improvement | Evidence of improvement |
|---|---|---|
| Tweets are weak and too verbose | Lead with the strongest supported fact. One complete sentence is welcome; add a second only for an essential qualifier, meaningful comparison or sourced consequence. Remove mandatory explanatory endings, generic meteorology and dramatic claims that outrun the evidence. | Blind comparisons on the same independently qualified evidence, judged for punch, clarity and unnecessary words. Record length and human edits. Shorter is a craft objective, not permission to drop forecast, place, date, scope or uncertainty. |
| Coverage misses the world | Preserve geographically distinct observations; expose fresh supply and gaps by region/hazard. Rank comparable global events before applying publication limits. Repair and qualify observed sources outside the US; retain honest forecast coverage where observation is unavailable. | Reference-event recall and explicit miss reasons, with source freshness and evidence class alongside output distribution. A city count or colored map alone does not establish coverage. |
| Sources keep failing | Diagnose actual failures, preserve last good data with its age, use bounded source-appropriate retries and backoff, and distinguish quiet weather from missing observations. | Reproduced failure, specific remedy, successful source-contract check and visible recovery; named access blocks remain open. Repeated identical failures do not trigger repeated paid diagnosis. |
| There are no useful graphics | Add reusable, data-driven graphics in the **next product phase**, alongside the shorter editorial format. Start with a qualified record comparison and a regional map or timeline selected by available evidence. | Mobile-readable previews with source, time, units, scope, forecast/observation label and alt text. Plot/text/evidence revisions agree; changed evidence invalidates obsolete media and approval. No invented imagery presented as weather evidence. |
| TheHeat costs too much to run | Treat LLM usage as a design constraint from now on. Apply cheap eligibility checks first, generate one routine draft, avoid repeat work on unchanged failures, reuse exact valid results, shorten common prompts and load only relevant source guidance. | Provider-attributed calls/tokens/retries/cache usage and cost per usable draft, publication and major event covered. Unknown charges remain unknown. Actual invoices and bounded trials establish savings; prompt character reduction alone does not. |
| The system keeps breaking | Prefer small deployable changes to the existing stack, reliable persistence, truthful run outcomes, focused regression tests and recoverable failure states. | Exact deployed version, required CI, source/run state readback, preservation of drafts/receipts, and recovery tests for each changed boundary. Large test totals are not proof that the product works end to end. |

## Immediate implementation sequence

1. Finish the current P05/P06 scientific contracts and release their bounded reviewed changes. They prevent the actual threshold/record, forecast/observation, source-classification and stale-baseline errors. Explain any temporarily withheld source lanes rather than presenting an empty queue as healthy global coverage.
2. Bring **P07/P07a and the economical part of P08/P32 forward**. Reconcile writer, checker and critic around the same evidence-grounded, compact voice. Remove the mandatory second sentence and unsupported exemplars. Prefer one routine sample; apply at most one deliberate editorial rewrite when enabled. Do not create an extra LLM stage to enforce rules that code can check. Review existing structured-output and negative-cache work before duplicating it.
3. Address **P09/P09a source failures and coverage bottlenecks in parallel** with that editorial work. A prettier writer cannot compensate for absent or unreliable worldwide evidence. Do not require a database migration before fixing an adapter, misapplied publication cap or order-dependent city scan.
4. Deliver the first **P31 graphics slice in the next product phase**, with reusable chart/map templates and local previews. Rendering should be deterministic and cached by source/claim/template revision, with no recurring image-model bill. Start with two formats that the qualified data actually supports; do not buy a media platform or require every tweet to have an image.
5. Continue the remaining authority, durable storage, event/ranking and web-desk packages where they remove measured breakage or enable these outcomes. Preserve the full ledger; reorder dependencies deliberately rather than silently abandoning scope.

## Cost and voice constraints

The existing monthly budget watch is an estimate/alert, not a complete enforced spending ceiling. The old writer-cost target and current configuration are not approval for a new all-in infrastructure budget. No new paid model evaluation, credits, hosting purchase or production publishing is authorized by this priority note.

Budget control must ultimately cover every LLM route: automatic generation, dashboard previews, safety, factual checks, criticism, rewrites, enrichment, repair and operational assistants. Separate required factual/safety validation from optional style experimentation. If required checks cannot run within the allowed budget, retain the evidence for review and show the block; do not skip a check and publish. Reuse requires matching evidence, text, policy, model and prompt versions; new evidence must escape a cached rejection.

The default voice is a sharp, global weather publication: concrete fact first, intelligible scale, proportionate certainty, then stop. Aim to leave space below the platform limit; do not impose a minimum length or manufacture a second sentence. Virality is an intended outcome, not a justification for sensationalism. Humor is optional and never directed at suffering. A narrow true statement is stronger than an inflated one.

The retained corpus is not a validated positive training set: 31 receipt-backed posts, seven posted-state/no-ID texts and 25 generation-memory texts with unverified publication. Twelve selected posts were corroborated live; eight selected lifetime view counts do not establish account-wide performance or causal lift. Keep the actual scientific findings and their limits attached to any rewrite evaluation.

## Completion reporting

Report progress against these six outcomes alongside task IDs. Distinguish implemented code, offline checks, deployed behavior, live source/provider recovery and measured editorial or cost improvement. Neither a reduced prompt nor a passing mocked test demonstrates cheaper, more viral production tweets by itself.
