# Source scope in the dashboard

Open **Sources**, then **Scope and limits** beneath a saved source row. The details
describe where the collector looks, its product family, provenance, collection
rule, time basis and story limits. These details come from a versioned inventory
of the wired alert collectors and leaderboard. Internal workflow counters are
labeled separately; an unfamiliar historical label remains unregistered.

A saved successful run does not prove that the source is available now. A registry
entry does not establish complete geographic coverage, provider quota, reuse
rights, scientific validity or permission to publish. Model forecasts, station
products, official warnings, cumulative reports and derived combinations retain
different meanings. Alternate products keep their own provenance. Collection rules
describe the collector's calendar and existing gates, not a provider update promise
or evidence that collection is enabled.

The API also reports wired collectors without any supplied saved rows. This is a
code-inventory gap, not a count of missed weather events or inactive sources. No
geographic/event denominator is inferred. The existing source-status and timing
projections keep their original semantics. This feature makes no source requests,
changes no flags and grants no approval or publication authority.

For maintainers, `src/data/source_registry.py` is canonical. Review a changed
adapter's scope, product type, calendar and limits, then run
`python scripts/gen_source_registry.py`. The committed dashboard JSON includes
hashes of the referenced local files. Python tests compare the actual alert
wiring and entry points with the registry, and check exact generated bytes; client
code is never imported to perform this check. Referenced-code hashes are drift
evidence, not a complete transitive/remote-source archive or a scientific verdict.
Keep unknown provider terms and per-story qualification unknown until independently
supported. Adding an adapter still requires its existing source and claim gates.
